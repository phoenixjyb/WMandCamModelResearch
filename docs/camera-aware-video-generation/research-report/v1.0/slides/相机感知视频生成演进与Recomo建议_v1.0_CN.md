# 1. 相机感知视频生成

**技术演进、Atlas 评估与 Recomo 建议**

- 从运镜提示词到标定空间模型
- Recomo Research · 2026 年 9 月 3 日

---

# 2. 研究问题

该方向怎样从“向左平移”走向显式相机位姿、内参、几何、世界记忆和可执行拍摄轨迹？

- 真正控制的是什么？
- 哪些能力可以米制验证？
- 什么应该进入世界模型？
- 什么必须保持显式和确定性？

---

# 3. 主要结论

胜出的方向不是更好的运镜提示词。

```text
相机契约
+ 持久化空间状态
+ 几何条件生成
+ 影视智能
+ 确定性执行
```

视频模型是渲染器和预测器，不是几何与机器人安全的唯一权威。

---

# 4. 相机感知能力阶梯

1. 语义运镜
2. 相对外参控制
3. 标定射线控制
4. 度量场景控制
5. 跨视角与四维一致性
6. 光学相机控制
7. 持久化空间世界模型
8. 可执行影视智能

---

# 5. 相机术语必须精确

- **外参：** 定义世界坐标中的旋转与平移
- **内参：** 焦距参数与主点
- **投影/畸变：** 针孔、鱼眼、径向/切向参数
- **光学：** 对焦、光圈、快门、曝光
- **时间：** 相机时间不总等于世界时间

Dolly 与 Zoom 可保持构图近似，却产生不同视差。

---

# 6. 从位姿矩阵到稠密射线

位姿与内参为每个像素定义一条世界观测射线。

- 逐像素几何比单个帧级位姿 Token 更丰富
- Plücker 射线成为常见条件表示
- 射线只给视线，不给表面深度

缺失的深度推动下一阶段。

---

# 7. 阶段 1——MotionCtrl 与 CameraCtrl

**MotionCtrl**

- 分离物体和相机运动
- 给预训练生成器增加显式轨迹

**CameraCtrl**

- 把标定转换为逐像素 Plücker Embedding
- 将相机特征注入视频生成层

---

# 8. 阶段 2——极线几何

**CamCo · CamI2V**

- 用极线限制跨视角特征检索
- 减少对应歧义
- 改善多视图一致性

剩余问题：训练数据以平缓、静态相机路径为主。

---

# 9. 阶段 3——视频 DiT 相机适配器

**VD3D** 把标定相机控制带入 Transformer 视频扩散。

**AC3D** 研究控制应在何时、何处进入：

- 相机运动主要是低频
- 全局运动在去噪早期建立
- 选择性早期条件可保留动态与外观

---

# 10. CogVideoX 需要纠正的理解

CogVideoX 是强视频 DiT Backbone。

其“3D VAE”指视频空间—时间压缩，不是度量三维场景。

```text
AC3D-CogVideoX
= CogVideoX 视觉先验
+ 标定相机适配器
```

---

# 11. 阶段 4——度量深度

**RealCam-I2V**

- 预测度量深度
- 把源图反投影为点云
- 对齐轨迹尺度
- 在估计场景中编辑路径
- 用几何预览约束生成

注意：度量质量仍受单目深度和标定限制。

---

# 12. 阶段 5——显式三维缓存

**GEN3C**

- 维护深度构建的三维缓存
- 在目标相机下渲染已知内容
- 视频模型补全显露与不确定区域

```text
计算已知视角变化
+ 生成几何无法确定的内容
```

---

# 13. 阶段 6——动态重拍与四维对应

**ReCamMaster · CameraCtrl II · RealCam**

- 改变视角但保持动态表演
- 扩大探索并支持流式运行

**Track2View**

- 投影三维轨迹规定源内容到目标内容的运动

世界时间和相机时间必须可分离。

---

# 14. 阶段 7——内参与镜头光学

**AKiRa · UCPE · DeltaCam · CameraAnything**

- 焦距与视场角
- 镜头畸变与投影
- Pitch、Roll 与重力
- 对焦与光圈
- 快门与曝光
- 原生分辨率与复合转场

---

# 15. 相机成为可建模模态

**4DiM · Rays as Pixels**

一个模型可支持：

- 视频 → 相机
- 相机 → 视频
- 相机 + 视频联合生成
- 位姿/时间条件新视角

目标从旁路条件转为联合空间分布。

---

# 16. Atlas 真正改变了什么

World Labs 将 Atlas 描述为：

- 从头预训练为空间模型
- 多模态自回归扩散 Transformer
- 在共享上下文中使用文本、带位姿图像、图像序列和深度
- 生成相机可控视频与几何相关输出
- 支持更长设计路径和场景复用

战略信号：相机几何正在进入基础模型接口。

---

# 17. Atlas 尚未公开证明什么

仍未披露或未验证：

- 逐帧内参与动态焦距
- 米制平移容差
- 畸变和重力约定
- 闭环漂移与动态世界记忆
- 延迟、显存、模型规模、权重和 API
- 与专门相机模型的同输入比较

Atlas 应被视为方向验证，而不是可复现依赖。

---

# 18. 开放问题

1. 相机/物体运动纠缠
2. 度量尺度完整性
3. 显露和未知真值
4. 闭环与重访
5. 重力、Roll/Pitch 与光学
6. 动态四维状态
7. 物理可执行性

测量 ≠ 重建 ≠ 生成。

---

# 19. Recomo 架构原则

1. **相机契约**——完成标定、模型无关
2. **持久化世界状态**——测量、重建、生成、动态
3. **生成渲染器**——补全未知外观与运动
4. **机器人编译器**——确定性可行性和安全

不建议用最新视频模型替换整个空间栈。

---

# 20. Recomo 参考流程

```text
用户意图
→ 影视 Planner
→ 相机契约
→ 机器人可行性
→ 可执行轨迹

持久化空间状态
→ 几何预览
→ 相机感知生成器
→ 几何 + 影视 Critic
↺ 返回规划
```

# 21. 标准相机契约

```text
C(t) = {
  T_world_camera(t), K(t), projection(t), distortion(t),
  focus(t), aperture(t), shutter(t), exposure(t), time(t)
}
```

物理链：

```text
世界 → 底盘 → 机械臂/举升 → 云台 → 相机
```

坐标、单位、时间基、标定和不确定性都要版本化。

# 22. Benchmark 设计

三类环境：

- 完成标定的合成场景
- Recomo 静态重复路径采集
- 同步动态真实场景

轨迹：

- Pan/Tilt/Roll
- Dolly/Truck/Crane
- Orbit/Look-at 与 Dolly Zoom
- 大视差
- 非水平云台基座
- Yaw 锁定/解锁
- 返回闭环
- 激进分布外路径

---

# 23. 四套独立分数

**Camera**——旋转、米制平移、ATE/RPE、内参

**World**——重投影、深度、轨迹、身份、闭环

**Cinema**——构图、动态、连续性、人类偏好

**Robot/System**——可达、碰撞、稳定性、显存、运行时间、失败率

画面漂亮但相机错误，仍然是相机失败。

---

# 24. 实验优先级

- AC3D-CogVideoX——射线条件基线
- RealCam-I2V——深度对齐度量控制
- GEN3C——显式三维缓存生成
- ReCamMaster / TrajectoryCrafter——动态重拍
- UCPE / CameraAnything——光学与姿态
- Track2View——显式对应
- Atlas——获得访问和公平评测条件后的参考

---

# 25. 最终建议

```text
Atlas式学习空间智能
+ 显式三维状态
+ Recomo 影视规划
+ 独立校验
+ 确定性机器人执行
```

先做功能对标，再训练 RGB—深度—相机联合模型；只有在度量和真实具身收益被证明后才扩大规模。
