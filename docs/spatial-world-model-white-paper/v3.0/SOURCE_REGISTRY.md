## Claim handling

Source presence is not an endorsement of every headline. Camera errors require the alignment protocol; memory reductions require the affected component; throughput requires the full serving configuration. Product disclosures are not specialist reproductions. Open code does not imply unrestricted weights, datasets, outputs or teacher use. The main papers intentionally avoid importing unsupported numerical rankings or budgets from the historical documents.
