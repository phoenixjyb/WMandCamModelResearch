# Proposed v3.0 — 2026-09-05

This is a new editorial revision, not a silent replacement of v1/v2 and not an empirical research release.

## Content

- Added parallel English and Chinese technical white papers with 14 corresponding main sections.
- Replaced the scalar capability ladder with independent camera, geometry, dynamics, memory, optics, systems, decision and evidence dimensions.
- Narrowed Atlas benchmark claims to reported system-level comparisons rather than causal proof of the camera interface.
- Updated task-specific comparison families and credited prior work in memory, sensing-query retrieval, counterfactual protocols, planning and cinematography.
- Defined shared-world candidate prediction, intervention invariants, realized-shot regret and budgeted evidence acquisition as hypotheses rather than established novelty.
- Preserved SpatialAnchor, SpatialContextPlan, ContextCompiler, StructuredRollout and authority boundaries while allowing learned selection and non-RGB predictions.
- Added offline/streaming separation; metric scale, K transforms, depth/range and temporal semantics; uncertainty calibration, freshness and evaluator-failure accounting.
- Replaced unmeasured scale commitments with E0–E3 and a release/resource/rights template.

## Traceability

- Mapped all 38 material audit items to editorial changes and remaining validation.
- Retained all 71 audit source identifiers, with explicit review/reproduction limits.
- Recorded original-versus-repository v2 identities and an editorial topic mapping. Original attachment byte import remains outstanding and is not claimed complete.
- Added a hash-verifying recovery utility for the original v2 sources, writing only into a separate archive directory.

## Repository safety

- Existing research-report v1.0 and white-paper v1.0/v2.0 files stay unchanged.
- Added read-only PR documentation validation and tests.
- Changed the legacy artifact workflow to manual, read-only temporary builds; removed automatic commits that could rewrite frozen documents after unrelated source updates.
- No model weights, benchmarks, new rendered publications or external paper full texts are included.
